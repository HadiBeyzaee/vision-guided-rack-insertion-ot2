# The abandoned offset-amount head

Asks "is the offset large in each of vertical, horizontal, rotation: yes/no yes/no yes/no" at 7 mm and 1.0° thresholds, served on port 5005.

This is the ancestor of the Coarse/Fine phase switch that ships, which asks the same question with a two-valued vocabulary at a 5 mm boundary. Kept because it shows where that design came from.
