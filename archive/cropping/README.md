# Crop rectangle searches

Margin permutations for both cameras, most with several rectangles commented out above the active one. That commented history is the search itself.

The rectangles that ship: ViRA coarse `{440, 80, 380, 230}` and fine `{450, 140, 460, 310}` in `../../training/dataset/crop_images.py`, and the top-down `{240, 320, 500, 200}` in `crop_images_topdown.py`.
